PROJECT OVERVIEW

About the project

Proyek ini dikembangkan sebagai bagian dari proses pembelajaran full-stack melalui kelas online dengan bantuan video tutorial. Proses pengerjaan mencakup pengembangan antarmuka serta pengelolaan data menggunakan Laravel dan MySQL.

Role Full-stack Development
Framework Laravel
Database MySQL
Project Scope Product Catalog, Product Details, Shopping Cart, Checkout, Admin Dashboard

PROJECT DETAILS

What was developed?

Proyek ini mencakup beberapa bagian utama yang saling terhubung untuk mendukung proses penggunaan aplikasi apotek.

01 / USER INTERFACE

Product Catalog

Halaman utama yang menampilkan daftar produk kesehatan dan informasi produk yang tersedia.

02 / PRODUCT DETAIL

Product Information

Halaman detail untuk menampilkan informasi produk sebelum pengguna melakukan pembelian.

03 / TRANSACTION

Shopping Cart

Fitur keranjang belanja untuk menampilkan produk yang dipilih pengguna sebelum proses pembayaran.

04 / ADMIN PANEL

Product Management

Halaman admin untuk mengelola informasi dan daftar produk dalam aplikasi.

05 / DEVELOPMENT

Backend Development

Penerapan framework Laravel sebagai bagian dari pengembangan sisi backend aplikasi.

06 / DATABASE

Database Management

Penggunaan MySQL untuk mendukung pengelolaan dan penyimpanan data aplikasi.
