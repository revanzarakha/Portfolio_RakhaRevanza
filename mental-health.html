PROJECT 02 / PYTHON · MACHINE LEARNING

Mental Health Analyzer.

Aplikasi skrining awal berdasarkan kuesioner DASS-21, menggunakan model klasifikasi untuk mengestimasi kategori depresi, kecemasan, dan stres serta menampilkan hasil melalui antarmuka Streamlit.

Python Machine Learning Scikit-learn Streamlit DASS-21
APPLICATION INTERFACE DASS-21 questionnaire

PROJECT OVERVIEW

About the project

Proyek ini merupakan penelitian dan pengembangan aplikasi machine learning menggunakan data jawaban 443 responden dari kuesioner DASS-21. Penelitian membandingkan dua algoritma klasifikasi, yaitu Logistic Regression dan Random Forest, untuk mengestimasi kategori depresi, kecemasan, dan stres.

Dataset 443 responden
Questionnaire DASS-21 · 21 Items
Programming Language Python
Classification Models Logistic Regression & Random Forest
Application Interface Streamlit
